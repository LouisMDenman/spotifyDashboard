# Spotify Statistics Dashboard

#### Deployed Website URL
https://lmdspotifydashboard.netlify.app/

#### Video Demonstration of Functionality
https://youtu.be/a758lUDXg1k

This project was created to further understand the use of API's and calling their functionality in React. Currently due to Spotify small app development constraints, it only works with my personal spotify account. Currently it displays the top 20 tracks associated with the account that is logged in, but there is potential to add more statistics in the future.
